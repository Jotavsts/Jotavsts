### IA e LLMs

- **Claude API:** integração do modelo a CRMs e sistemas web, com desenho de prompts e fluxos que ligam a resposta do modelo ao restante do sistema.
- **Agentes:** uso o Claude Code com subagentes, skills e MCP, guiados por especificação técnica (`CLAUDE.md` / `AGENTS.md`), com revisão e validação de tudo que a IA entrega antes de publicar.
- **Automação:** captação de leads, atendimento e rotinas de CRM ligadas a APIs externas.
- **Estudando agora:** LangChain, PydanticAI, MCP como desenvolvedor e métricas de avaliação de respostas de LLMs.
